### 5. Live matrix and variant contract

Case registry `T349MySqlFunctionCases.cs`: one stable record per inventory name and per overload/variant: `case ID; name; capability key; disposition; typed expression factory; raw SQL; setup/cleanup; expected CLR type; value comparator; NULL policy; invalid-input policy; determinism/session policy`. Typed/generic case implementations, not string/double conversion of everything.

The 90 open names = **86 planned live scalar names + 4 pre-SQL refusals**. Do not misreport refused names as successful live scalar executions. Include `JSON_STORAGE_FREE` as the 91st regression/control record.

Oracle-before-assertion protocol (one leased MySQL session): record server/version, SQL mode, charset, collation, timezone, component prerequisites; set up isolated probe tables with `try/finally`; execute raw ADO.NET oracle cases first, recording returned CLR type, value/binary encoding, warnings/errors and session setup; flush `oracle.jsonl`; only then execute/assert translated cases.
