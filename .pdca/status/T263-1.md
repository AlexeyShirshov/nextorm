## 2. Root cause

The reported "both operands parameterised" form is only one broken form.

- `JsonSqlTranslator.cs:87–98` sends all six overloads through untyped operator emission.
- `JsonSqlTranslator.cs:191–195` delegates to `SqlOperandTranslator.EmitOperator:226–243`; argument emission uses `AppendArgument:26–53`.
- **Literal form:** `BaseExpressionVisitor.cs:757–784` emits bare quoted literals, producing `('{"a":1}' -> 'a')`, without operand casts. The supplied finding also identifies absent string escaping on this path.
- **Captured/parameter form:** `MemberTranslator.cs:456` and `BaseExpressionVisitor.cs:584–590` emit parameters. `PostgresDataContext.cs:128–162` leaves ordinary strings as text but assigns JSONB binding to `JsonDocument`/`JsonElement`/`JsonNode`.
- Casting the document alone does not settle a bare unknown string key: PostgreSQL still has text-key and integer-index operator candidates.
- The call reaches translation through `NormSqlTranslator.cs:578` and `BaseExpressionVisitor.cs:405`; it is not folded into a CLR result.
- Existing translator casts at `JsonSqlTranslator.cs:264–303` establish the appropriate implementation layer.

No change to global parameter binding or the public declarations at `SqlFunctions.Postgres.cs:153–168` is required.

## 3. Decision: contextual casts, preserving native document expressions

### Three answers

- **Essence:** give PostgreSQL sufficient operand types at these six translation sites.
- **Constraints:** retain column semantics, overload identity, null propagation, provider guards, safe literal encoding, and existing parameter/cache behavior.
- **Minimum solution:** one private JSON-access emitter in `JsonSqlTranslator`, with document provenance preserved and right operands typed from the resolved overload.

### Selected SQL rules

Let:

- `V` be a raw client value: a literal, captured value, or explicit parameter.
- `E` be a mapped native `json`/`jsonb` column or an existing server-side JSON expression.
- `Q` be `cast(V as jsonb)` for raw values, otherwise unchanged `E`.

Required shapes:

| Overload | SQL |
|---|---|
| `json_get(document, string?)` | `(Q -> cast(K as text))` |
| `json_get(document, int)` | `(Q -> cast(I as integer))` |
| `json_get_text(document, string?)` | `(Q ->> cast(K as text))` |
| `json_get_text(document, int)` | `(Q ->> cast(I as integer))` |
| `json_get_path(document, string?[])` | `(Q #> cast(P as text[]))` |
| `json_get_path_text(document, string?[])` | `(Q #>> cast(P as text[]))` |

Examples of required shapes:

- Literal document/key: `(cast('{"a":1}' as jsonb) -> cast('a' as text))`.
- Captured document/key: `(cast(@p0 as jsonb) -> cast(@p1 as text))`.
- Explicit `JsonDocument` parameter: `(cast(@norm_p0 as jsonb) -> cast('name' as text))`.
- Native column: `(column -> cast('name' as text))`, **without** a document cast.

Raw structured JSON parameters are already JSONB according to the supplied binding evidence; a contextual JSONB cast does not change their native binding.

**Provenance rule:** distinguish captured values from mapped members using the existing semantic translation machinery. Do not infer "captured" merely because an expression is a `MemberExpression`. Do not evaluate query expressions to discover their values.

**Literal rule:** document and string-key literals in this emitter must use safe SQL literal encoding. If no suitable existing encoder exists, add a private local encoder for these accessors only. Do not change the global `VisitConstant` policy in this unit.

### Alternatives

| Approach | Benefit | Cost/risk | Decision |
|---|---|---|---|
| Cast every document to JSONB | Smallest mechanical change | Changes native `json` column/function semantics and SQL result types | Rejected |
| Parameterize all operands globally | Avoids literal ambiguity and interpolation | Changes unrelated SQL, parameter numbering, cache/binding behavior; parameters alone do not solve text-document operators | Rejected |
| Cast document literals only | Very small patch | Misses captured text documents and ambiguous/null right operands | Rejected |
| Contextual document casts plus overload-specific right casts | Fixes both reported forms; preserves native columns | Requires a small, verified provenance distinction | **Chosen** |

No API break is authorized. A change requiring global binding, signature, return-contract, or unrelated scalar-translation changes returns to PLAN.
