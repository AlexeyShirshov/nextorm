## Goal / expected result

A **runtime-factory** TVF body applied to an arity-2 **joined receiver** —
`joined.CrossApply(p => Tvf.Echo(p.Item1.Id))` — works on #324's flat transition with correlation
bound to the correct slot (FROM + exactly the preceding joins), instead of throwing
`InvalidOperationException: No coercion operator ... 'TvfEntityBuilder<T>' and 'QueryCommand'`.
Composed correlated TVF bodies (`p => Tvf.Echo(p.Item1.Id).Where(...)`) get an intentional,
composition-specific `NotSupportedException` **before compilation** that names the composition and
points at the supported derived-query form.

## Form / overlay

`form = cycle` — one known seam (`EntityBuilder.ApplyCorrelatedJoin` reusing
`SourceExpressionLowerer.TryCreateCorrelatedTvfApply`), bounded volume (one production seam + one
narrow guard + focused tests + EN/RU docs). Overlay `pdca-dotnet` + project overlay `nextorm-pdca`.

1. Reuse `TryCreateCorrelatedTvfApply<TAppliedEntity>` in `ApplyCorrelatedJoin` (mirror of
   `JoinApply`, `src/nextorm.core/Builders/EntityBuilder.cs:3885-3894`).
