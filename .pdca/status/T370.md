## Scope

### Stream A — compile-time query pipeline (primary)

Replace runtime type derivation with compile-time generation so no runtime-typed `Type` feeds the materializer/projection/command path:

- generate row materializers and projection bindings (constructor + member binding) instead of `Type.GetConstructors()`/`GetProperty` + `Expression.New`;
- remove the runtime carriers (`QueryCommand.ResultType`, `ProjectionEntityItem.EntityType`) at their construction points;
- eliminate `MakeGenericType`/`MakeGenericMethod`/`Expression.Lambda` from the query path where the shape is compile-time known;
- design and approve the registration/discovery contract for dynamically composed queries and external assemblies **before** implementation (a public-surface change here needs an approved design; no silent API narrowing).

First concrete increment (measured in #366 S10 reconnaissance): the remaining `RowMaterializerBuilder` constructor cluster — 5 `IL2070` rows plus the `Range<T>` cached-lambda row. Carrying the constructors gets to −9 with two relocated sites (entity ctor into `EntityMetadata`), net −7; the relocation direction is a design decision for this issue.
