### 2. Root cause

- `JoinAliasGenerator.cs:1361-1386`: extension rendering always emits/forwards a source.
- `:284,547-550`: argument-count and step-reader gates assume the explicit-source layout.
- `:675-709`, especially `:699-706`: joined-type discovery reads argument zero as a source.
- `EntityBuilder.cs:2916-3050`: public alias seams require explicit sources; emitted consumer code cannot use internal `DataProvider` (`:94`).
- `AliasGeneratedSurfaceTests.cs:132-167`: unconditional “marker overloads have no options” freeze conflicts with the addition.
- Binding is established: closed receivers at generator `:1332-1352`, exactly one method type parameter at `:1355-1357`; explicit `<TJoin>` therefore binds.
- `IsCandidate:217-221` already accepts the two-argument marker-last shape. Extend classification/emission rather than replacing discovery.

### 3. Minimal solution and alternatives

**Essence:** create the implicit source inside core and reuse alias projection/state assembly.
**Constraints:** public-only generated calls; exact explicit-generic syntax; unchanged old overloads/cache/provider semantics.
**Minimum:** one source-less predicate alias seam, a generator form branch, and focused tests/docs.

| Approach | Benefit | Cost/risk and decision |
|---|---|---|
| Public source-less `JoinAlias` seam + generated closed-receiver extensions | Core owns `From<TJoin>()`, guards and options; existing alias assembly reused | Moderate generator/plumbing work. **Choose.** |
| Hand-write 28 overloads | Familiar positional locations | Core cannot reference arbitrary consumer-generated marker types (`:205-229,786-794`). Reject. |
| Runtime `JoinOptions.Alias` | Apparently small addition | Cannot create compile-time `[JoinSlot]` members (`:1155-1161`); changes requested API. Reject. |
| Emit captured `ctx.From<T>()` or IDataContext calls | Avoids seam | Context recovery is unavailable through the receiver’s public surface (`EntityBuilder.cs:27,94`); unnecessary coupling. Reject. |
| Defer chained receivers | Smaller patch | Violates arity acceptance and ignores generated transitions (`:1189-1236`). Reject. |

The public seam takes factory, condition, JoinType and optional options; internally creates the source and reuses `JoinAliasEntity`/`CreateAliasJoined` (`EntityBuilder.cs:3064-3169`). Apply options once using established join-option semantics, not independently in wrapper and helper.

**Freeze decision:** preserve source-explicit marker-last/option-less signatures; add a distinct source-less freeze with optional options after marker. Keep type-name and uniqueness assertions.
