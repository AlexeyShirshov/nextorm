### Frozen design decision

- A reader-factory expression arm plus one scalar conversion helper, governed by provider DataContext policy. No arm in the generic `SelectExpression.GetDataRecordMethod` switch and no new dialect capability member.
- Core `DataContext`: `protected virtual string? TimeOnlyProjectionRefusal` defaulting to `"TimeOnly projection refused for this provider: no verified native time-of-day reader."`, plus an internal forwarding accessor for `QueryExecutor`.
- SQL Server and PostgreSQL override to `null`. MySQL, MariaDB, SQLite, ClickHouse override with the exact strings below; MariaDB overrides its inherited MySQL value explicitly.
- The policy is passed from core `DataContext.MapColumnExpression` into `RowMapperFactory.MapColumn` as an added argument; internal callers default to the generic refusal, never silently to support. Resolve every caller with Roslyn.
- Converter precedence preserved. The `TimeOnly` branch sits after converters and beside, not inside, the existing `TimeSpan` branch; existing nullable/default-on-null wrappers kept.
- New internal `TimeOnlyProjectionReader.ReadNative(object value, string? refusal)`: on permitted providers accept only native `TimeOnly` or `TimeSpan`; for `TimeSpan` require `0 <= value.Ticks && value.Ticks < TimeSpan.TicksPerDay`, then `TimeOnly.FromTimeSpan`. Never modulo, truncate, parse strings, reinterpret integers or use `Convert.ChangeType`.
- Compiled expression shape: `Expression.Call(ReadNativeMI, Expression.Call(param, GetValueMI, Expression.Constant(column.Index)), Expression.Constant(refusal, typeof(string)))`, composed in `RowMapperFactory`; `GetValueMI` stays the instance `IDataRecord.GetValue(int)` method. A static helper is never returned from `GetDataRecordMethod`.
- For refused unconverted mapped columns, throw the named `NotSupportedException` while constructing the mapper, before nullable wrappers can disguise refusal as successful null support.
- `QueryExecutor`: thread the same context policy into the scalar conversion seam; handle `TimeOnly` and `Nullable<TimeOnly>` before the identity/`ChangeType` fallbacks via `ReadNative`, preserving null behaviour; guard refused providers before any native-`TimeOnly` identity shortcut.
- Converter-owned projections keep their existing conversion route; prove they do not enter the new unconverted scalar guard; repair routing only inside the permitted reader/executor scope.
- Provider outcomes: SQL Server supported (native `time(7)`/computed time arrives as `TimeSpan`, 100 ns); PostgreSQL supported (native `time` arrives as `TimeSpan`, µs; no new claim for `timetz`/intervals/raw path). MySQL refused: `"TimeOnly projection refused for MySQL: TIME is a duration; use TimeSpan or an explicit value converter."`; MariaDB refused: `"TimeOnly projection refused for MariaDB: TIME is a duration; use TimeSpan or an explicit value converter."`; SQLite refused: `"TimeOnly projection refused for SQLite: there is no native time-of-day type; use an explicit value converter."`; ClickHouse refused: `"TimeOnly projection refused for ClickHouse: there is no native time-of-day type and TimeOnly is bound as String; use an explicit value converter."`.
- Permitted provider, out-of-domain value: `NotSupportedException("TimeOnly projection value is outside [00:00:00, 24:00:00); use TimeSpan.")`. Permitted provider, alien native representation: `NotSupportedException("TimeOnly projection requires a native TimeOnly or TimeSpan value; use an explicit value converter.")`.
- Alternatives rejected: a generic switch arm is smaller but cannot express the conversions/refusals; provider-only overrides duplicate conversion and miss scalar terminals.
