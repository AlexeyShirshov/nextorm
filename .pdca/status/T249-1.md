## Normative API (from issue §2 — unchanged wording)
```csharp
ctx.From<Order>().LoadWith(o => o.Items);
ctx.From<Order>().LoadWith(o => o.Customer);
ctx.From<Order>().LoadWith(o => o.Items,
    c => c.From<Item>().Where(i => i.Active).LoadWith(i => i.Product));
ctx.From<Order>().LoadWith(o => o.Customer,
    c => c.From<Customer>().Where(x => x.Active));
```
Both aggregate kinds need short and `Func<IDataContext, EntityBuilder<TChild>>` forms, both accept the existing `EagerLoadMode` (`Default` by default), bare form uses the current context's normal related-type source, the explicit `childQuery,parentKey,childKey` overload keeps its signature and contract. Collection binding must never take a reference route; the child builder's RelatedType is validated. No new `Include`/`ThenInclude` names; `AsEntityBuilder` outside an expression tree stays an expression-only marker that throws.
