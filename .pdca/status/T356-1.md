### Fix (D2)

`src/nextorm.core/Query/QueryCommand.QueryPreparer.cs:653-691` (identity whole-projection arm):

1. the arm now additionally requires `identityMeta.Properties.Count > 0` — exactly the condition under
   which `EntitySelectListBuilder.Build` yields columns (`Build` emits one column per mapped property),
   so a scalar CLR type (raw/bind auto-registers its metadata with zero properties) can never be treated
   as a mapped entity and can never obtain an entity-projection cache entry;
2. an EMPTY `SelectListCache` entry is treated as a miss (`|| identityColumns.Length == 0`), so a
   hand-seeded/legacy empty entry can never be authoritative.

With the guard the scalar arm (`IsSingleColumnProjection(body.Type)`) owns the identity read of a
single-column derived source, warm and cold alike.

## DO verification addendum (independent controller run)

Root cause: the identity-projection arm of `QueryCommand.PrepareColumns`
(`src/nextorm.core/Query/QueryCommand.QueryPreparer.cs:650-676`) accepted **any** metadata entry for
the projection type as "a mapped entity". The raw/bind path auto-registers metadata for arbitrary
result CLR types, and such an entry maps **no properties**; `EntitySelectListBuilder.Build` therefore
yielded an **empty column list**, which was then written to the process-wide
`DataContextCache.SelectListCache` under the scalar type (`typeof(int)`). Every later identity read of a
single-column derived source of that type resolved to that zero-column entry — the statement rendered as
`select` with nothing after it, and the driver reported the damage as a truncated text
(`near "from"`). That is why the reproducer is green alone and red in a full suite: the poisoning needs
another query to have run first, on the same process, for the same CLR type.

Fix at the invariant, two conditions:
1. the arm requires `identityMeta.Properties.Count > 0` — a property-less metadata entry is not a mapped
   entity, so the scalar arm below owns that shape warm and cold alike;
2. an **empty** cached entry is treated as a miss (`|| identityColumns.Length == 0`) — a hand-seeded or
   legacy empty entry can no longer shadow the ordinary build, and the arm cannot create one because it
   now requires mapped properties.

Regression test: `tests/nextorm.sqlite.tests/SqlGeneration/T356ScalarIdentityCacheTests.cs` — two
deterministic arms that construct both state shapes through the public API on one context
(property-less metadata entry; empty select-list entry), no suite ordering involved.
