differentially (E21/E22): a global hot-path regression, not CTE-edge logic; r=5 removes the representation

**Final fix:** replace the nested description storage with a **flat copy-on-write root**.

- Move every block-backed slot into `QueryDescription`; remove the four block classes, their `Empty`
  singletons and the block-level `Shared` flags; keep **root-only** `Shared`.

  fast/slow conditions and root sharing stay unchanged.
- Leaf accessors read flat root slots; writers obtain the writable root before mutation.
- Preserve logical group materialization through root presence bits, default-write elision, nullable
  distinctions, meaningful null writes and collection ownership.
- No deep copies; no per-query allocation added; the **memo 0 B test stays mandatory**.
