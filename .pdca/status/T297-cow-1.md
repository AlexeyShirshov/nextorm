### Minimal solution: objective, constraints, optimum

**Objective:** remove repeated description/state allocation, not eliminate real CTE body commands.
**Constraints:** public command façade and existing semantics remain.
**Choice:** A, with sharing initially enabled only at CTE construction/clone boundaries.

| Shape | Benefit | Cost/risk | Decision |
|---|---|---|---|
| A: slim command + immutable description + lazy state | Removes eager state/comparers and permits description sharing | Broad storage migration; all command consumers require regression coverage | **Choose** |
| B: unchanged command + shared core | Smaller implementation boundary | Cannot remove existing inline command payload; shared mutable state adds isolation risk | Reject |
| C: lazy `CteDefinition.Query` | Defers unused bodies | Real paths require preparation, hashes, rendering and cloning; materialization defeats the saving | Reject |

**Exact proposed logical layout; x64 byte counts are hypotheses, not measurements:**

- `QueryCommand`: header 16 B + four references (`description`, `preparation`, `_dataContext`, `binding`) = **48 B**; keep public inheritance, signatures and virtual behaviour unchanged.
- Immutable internal description: header 16 B + eight references (`Exp`, `SrcType`, `ProjectionType`, predicates, relations, ordering, clauses, options) + one 64-bit flag word = **88 B**.
- Predicates hold condition/group/having/prewhere/filter scope; relations hold joins/CTEs/referenced queries/outer references/union; ordering holds paging/sorting; clauses/options hold the remaining raw registry fields. Optional blocks use immutable empty singletons.
- Node-owned preparation holds prepared source/select/grouping/array-join/conditions, preparation flags, result/shape/scan state, twelve hashes, six `this`-capturing comparers and hoisted-state overrides. Allocate on preparation or an existing explicit stateful access; default getters must not allocate.
- Node-owned optional binding holds `TypedRecursiveAnchor` and per-command cache-policy state, including `_dontCache`; never share it. Preserve existing defaults, transitions and `HasEverPrepared`.
- Every raw mutation replaces that node's description/block; preparation and binding never cross command ownership. Do **not** assume referenced expressions or caller-owned collections are deeply immutable: retain existing aliasing semantics or use the existing non-sharing path.
- Minimal slice is the storage migration plus CTE-edge sharing—not a new preparation recipe, hash algorithm, SQL renderer or public descriptor API. Broader sharing stays in this milestone as follow-up units, not as a substitute for these six criteria.
