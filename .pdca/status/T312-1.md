## Goal, invariant, and acceptance
- Goal: execute supported computed-scalar derived sources without changing named-column semantics, public APIs, provider parity or unrelated SQL.
- Invariant: an identifier referenced outside a derived source must actually be exposed by that source.
- **AC1:** SQLite and PostgreSQL execute `From(inner).OrderBy(x => x).Select(x => x * 3)` and return exactly `[6, 12]`. Missing-column errors, wrong order, empty or different results fail.
- **AC2:** Both providers execute plain `From(inner)`, nested derived sources and a derived join with independently specified expected values. SQL-generation-only evidence fails.
- **AC3:** Both providers execute the actual `AsTempTable`/CTAS path and return `[6, 12]`. A plain-subquery substitute fails.
- **AC4:** Decoded inner output identifier equals the outer reference, with correct provider quoting, exactly one declaration for the affected scalar and no duplicate output identifier. Merely finding `c0` fails.
- **AC5:** Preserve named anonymous projections, physical spelling/case, float projections, JSON shape mode, typed CTE naming and materialization. Blanket case changes, duplicate `AS`, shape changes or materializer regressions fail.
- **AC6:** Build has zero warnings; FluentAssertions, CRLF, CPM, coverage and provider-execution policies remain satisfied. Lowering thresholds or counting selected skips as passes fails.
- **AC7:** No new public API, snapshot hiding or expansion into #294/#300/#315. Changing the protected exact-SQL cases instead of preserving them fails.

## Root cause
- `QueryPreparer.cs:748-751`, within `:722-769`, assigns `OutputName="c0"`.
- Derived rendering uses `ExactProjectionAliases=false` at `SqlSourceRenderer.cs:559-575`; its rationale is documented at `:571-574`.
- `SqlBuilder.cs:548-560` ignores that output name; `SqlDialectBase.cs:441-443` emits nothing for a null name. `SqlSourceRenderer.cs:1183-1186` is not the operative path.
- `MemberTranslator.cs:858-884`, especially `:870`, nevertheless resolves `PropertyName ?? OutputName`.
- SELECT versus ORDER BY differs through `DontNeedAlias` (`SqlBuilder.cs:548` versus `:122-130,:379`), not `HasAliases`.
- Predictor/consumer anchors: `QueryPreparer.cs:586-599,:928-957,:1493-1509,:1522-1551,:1586-1605,:2013`.
- CTAS path: `TempTableExtensions.cs:322-326` → `DataContext.cs:1322-1332` → `QueryPlanner.cs:128-163`.

## Minimal solution and alternatives
- **Essence:** expose an already-planned scalar output name at the two boundaries that require it.
- **Constraints:** preserve physical/named columns, existing alias suppression, typed CTE and JSON policies; introduce no public naming guarantee.
- **Optimum:** one documented internal boundary-context bit, existing `OutputName`, one shared prediction rule; no new generated-name sequence.

| Approach | Benefit | Cost/risk | Decision |
|---|---|---|---|
| Boundary-local generated alias | Repairs derived and CTAS output contracts narrowly | Small internal context/predictor change | **Choose** |
| Blanket `ExactProjectionAliases=true` | Reuses existing switch | Violates `:571-574`; physical-name/case regressions | Reject |
| Typed preparation exception | Avoids malformed SQL | Rejects a representable supported query; fails AC1 | Reject |
| Inline expression | Avoids output reference | Duplication, parameter/evaluation and nesting/CTAS risk | Reject |

### Concrete seam rule
- Add internal context bit `RequireDerivedScalarOutputName`; document its boundary-only meaning.
- Set it for derived-subquery projection rendering at `SqlSourceRenderer.cs:559-575` and CTAS source projection rendering at `QueryPlanner.cs:128-163`; default false elsewhere. Restore prior context after each boundary; do not mutate shared command state.
- Read it at `SqlBuilder.cs:548-560`. Existing expression rendering and `DontNeedAlias` suppression remain authoritative.

| Condition, evaluated in order | Rendering decision |
|---|---|
| JSON mode or typed CTE `ExactProjectionAliases` policy applies | Existing policy, unchanged |
| `DontNeedAlias` suppresses declaration | Existing suppression; no added `AS` |
| `PropertyName != null` | Existing named/physical-column behavior |
| `PropertyName is null`, `OutputName is null` | Existing nameless behavior |
| `PropertyName is null`, `OutputName != null`, bit false | Existing behavior |
| `PropertyName is null`, `OutputName != null`, bit true | Declare the provider-quoted `OutputName` exactly once |
