## 1. Goal (essence)

Deliver a bounded MariaDB-only JSON slice through the existing `SqlFunctions.MySql` surface: on MariaDB **11.4** a user can call `json_equals` and `json_normalize`, get correctly materialised values, and every other provider rejects both names with the existing explicit `NotSupportedException`. The rest of #284 stays open in the same issue/milestone.

## 2. Acceptance criteria (observable behaviour + negative case)

| ID | Criterion | Observable behaviour |
| --- | --- | --- |
| R01 | `json_equals` | rendered SQL `json_equals(lhs, rhs)`; live 11.4: equal JSON → `1`, different → `0`, CLR result `int?`; negative: MySQL/other providers throw. |
| R02 | `json_normalize` | rendered SQL `json_normalize(j)`; live: JSON `true` → text `true`; reordered object keys normalise equal; idempotent; `string?`. |
| R03 | nullable equality | `(NULL, valid)`, `(valid, NULL)`, `(NULL, NULL)` → SQL NULL, distinct from JSON text `"null"`. |
| R04 | undocumented `json_normalize(NULL)` | the API result must equal an **independent raw ADO.NET** observation on 11.4 (recorded, then asserted; never a dynamic expectation). |

Exact SQL expectations: `json_equals(somestring, '{"a":1}')`, `json_equals('{"a":1}', '{"a":1}')`, `json_normalize(somestring)`, `json_normalize('{"b":true,"a":false}')`; `Render("json_equals", ["lhs","rhs"]) == "json_equals(lhs, rhs)"`, `Render("json_normalize", ["j"]) == "json_normalize(j)"`. Captured JSON argument is bound as a parameter (payload never interpolated); the exact placeholder spelling is observed in D1 and asserted.

## 3. Public API (planned, not existing symbols)

```csharp
public int? json_equals(string? json1, string? json2) => default!;
public string? json_normalize(string? json) => default!;
```

`int?` (not `bool?`): there is no boolean-returning precedent on `SqlFunctions.MySql` (`find_in_set -> int?` at `SqlFunctions.MySql.cs:24`), the documented SQL result is `1/0/NULL`, and the protocol type of a computed `JSON_EQUALS` is unproven. XML `<summary>` names the SQL function and says "MariaDB-only".
