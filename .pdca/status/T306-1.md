## Goal
Make single-source mapped-entity `From<T>().Select(x => x)` reuse ordinary entity column selection and its cache, without another projection pipeline; the rendered statement must be the full correct SELECT and the query must materialize rows.

## Acceptance criteria
- **AC1 (positive):** normalized `CommandText` is exactly `select id, name\n from entity_parent\n order by id` for both identity projection and the unchanged `ToCommand()` control (normalization: CRLF→LF only; no trimming/rewriting).
- **AC2 (failing→passing):** in the current worktree, the planned regression tests against unmodified `src/` render `selec\n from entity_parent\n order by id` and live SQLite throws `Microsoft.Data.Sqlite.SqliteException`, error 1, `near "selec": syntax error`; after the fix the same commands pass and identity materializes exactly 2 rows matching the control's IDs, names and ordering.
- **AC3 (negative):** unsupported whole-object shapes must not become identity projections; an empty prepared select list throws an existing typed exception before SQL truncation; a **null** select list retains its existing wildcard behavior.
- **AC4 (preservation):** derived-source and joined-item identity, nested rendering, plan-cache identity differentiation, shared-command state, temporary-table and TVP paths remain correct; warnings/errors remain zero.

## Root cause
`EntityBuilder.cs:331,343` sets `Exp` and clears `SrcType` → `QueryCommand.QueryPreparer.cs:77-84,95,99` → `PrepareColumns:513`; the identity arm `:574-599` requires `_from.ColumnShape`, absent for a physical single source; no branch assigns the select list → `:977` returns null → `:135` stores `[]` (empty, non-null) → `SqlBuilder.cs:506-510` treats only **null** as wildcard, `:580` unconditionally does `selectBuilder.Length -= 2`, turning `select ` into `selec`.

## Decision and rejected alternatives
- **B (chosen):** repair `PrepareColumns` identity arm — resolve the mapped single source through the existing `EntitySelectListBuilder.Build` (`DataContext/EntitySelectListBuilder.cs:22`) and `DataContextCache.SelectListCache` (`DataContextCache.cs:75`); preserve the existing derived/join branch precedence.
- **C (chosen, same unit, defensive):** fail closed on an empty select list in `SqlBuilder.MakeSelect` with the existing `BuildSqlCommandException` (precedent `SqlBuilder.cs:531-537`); never infer columns in the renderer. No new exception/factory/abstraction/public member.
- **A rejected:** altering `EntityBuilder.SelectCore`/`SrcType` affects the broad fluent contract and collides with T249/T251/T309/T322.
- **C alone rejected:** a renderer guard cannot restore projection semantics and would duplicate preparation.
