**Goal:** portable explicit NULL placement for ordinary query ordering, with placement-aware plan identity and in-memory parity. Existing calls and explicit `Default` retain baseline SQL byte-for-byte and retain existing behavior.

**Minimal solution:**
1. Extend `Sorting` and ordering APIs with `NullsPosition`.
2. Render placement at the three emitters consuming `cmd.Sorting`, using native syntax or CASE emulation.
3. Include placement in plan equality/hash, preserve it through `ForLast`, and implement explicit placement in memory.

# Dialect renderer matrix

`K` is the existing correctly qualified/quoted key expression. These are exact explicit-placement fragment oracles. Descending key direction is rendered as ` desc`; ascending key direction has no suffix.

| Dialect | Capability | ASC/FIRST | ASC/LAST | DESC/FIRST | DESC/LAST |
|---|---:|---|---|---|---|
| SQLite | true | `K NULLS FIRST` | `K NULLS LAST` | `K desc NULLS FIRST` | `K desc NULLS LAST` |
| PostgreSQL | true | `K NULLS FIRST` | `K NULLS LAST` | `K desc NULLS FIRST` | `K desc NULLS LAST` |
| ClickHouse | true | `K NULLS FIRST` | `K NULLS LAST` | `K desc NULLS FIRST` | `K desc NULLS LAST` |
| SQL Server | false | `CASE WHEN K IS NULL THEN 0 ELSE 1 END ASC, K` | `CASE WHEN K IS NULL THEN 1 ELSE 0 END ASC, K` | `CASE WHEN K IS NULL THEN 0 ELSE 1 END ASC, K desc` | `CASE WHEN K IS NULL THEN 1 ELSE 0 END ASC, K desc` |
| MySQL | false | Same CASE oracle | Same CASE oracle | Same CASE oracle | Same CASE oracle |
| MariaDB | inherited false | Same CASE oracle | Same CASE oracle | Same CASE oracle | Same CASE oracle |

**Default:** bypass new rendering and preserve captured SQL bytes, including current whitespace and direction spelling.
- SQLite/PostgreSQL/ClickHouse override the capability.
- SQL Server/MySQL use the default implementation; MariaDB inherits MySQL behavior.
- No `SqlServerDialect.cs` edit.
- The CASE prefix is always ascending, including descending requested keys.
- For index overloads, resolve the actual key before emulation. Never emit `CASE WHEN 1 IS NULL`.
- Retain alias qualification and parameter binding when the key is emitted more than once.
- Do not change paging fallback, LIMIT BY or SETTINGS placement.

**Unsupported shapes:** invalid enum/index values fail before execution. For CASE shapes that cannot be rendered legally without changing result semantics—such as a prohibited DISTINCT ordering expression or unsafe expression duplication—fail closed with a documented exception. Do not silently default.
