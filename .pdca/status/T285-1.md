## 1. Цель и критерии приёмки

Добавить только нативный агрегат SQLite `total`, сохранив существующий путь трансляции и поведение остальных провайдеров.

**Решение:** четыре остальных имени issue — `median`, `percentile`, `percentile_cont`, `percentile_disc` — откладываются: все требуют неподтверждённого для bundled SQLite 3.53.4 `SQLITE_ENABLE_PERCENTILE`, а `median` дополнительно перехватывается name-only веткой ClickHouse в `AdvancedAggregateTranslator.cs:160`; публикация неподтверждённых функций воспроизвела бы #278.

**Следствие:** #285 остаётся открытым ровно с этими четырьмя residual names; milestone не меняется.

## 2. Минимальное решение

### 2.1. Три ответа

- **Суть:** открыть существующий SQLite-specific translation seam для одного нативного агрегата.
- **Ограничения:** только два product-файла; без нового translator, изменения общего aggregate dispatch, runtime capability framework, состояния cache и эмуляции функций.
- **Оптимум:** facade member плюс имя в whitelist renderer; остальное — тесты, документация и доказательства.

### 2.2. Установленные причина и seam

Facade расположен в `src/nextorm.core/Query/SqlFunctions.Sqlite.cs`: `SqliteFunctions : CommonFunctions` на `:83`, `Sql.Sqlite` на `:12`; instance expression-only методы без атрибутов подтверждены на `:118`, `:166`, aggregate precedent — `json_group_array<T>(T? value)` на `:248`.

Путь: `BaseExpressionVisitor.VisitMethodCall` (`Visitors/BaseExpressionVisitor.cs:405`) → `NormSqlTranslator.TryTranslate` (`:30`, проверка `CommonFunctions` на `:39`) → `TranslateNormSql` (`:204`) → `BuiltinFunctionTranslator` (`:542`) → `AdvancedAggregateTranslator` (`:557`) → `SqliteFunctionTranslator` (`:563`).

`src/nextorm.core/Visitors/SqliteFunctionTranslator.cs` проверяет точный `DeclaringType` на `:53`, capability/whitelist на `:58`, alias на `:136`, выполняет emission на `:137`. Renderer находится в `src/nextorm.sqlite/SqliteFunctionRenderer.cs`: whitelist `:16–24`, `Supports` `:35`, generic emission `:54`.

`total` отсутствует в name-based cases `AdvancedAggregateTranslator.cs:29` и не перехватывается блоками `count`/`min-max`/`sum-avg` в `NormSqlTranslator.cs:368,:448,:486`. Поэтому двух product-файлов достаточно. Это дополнительно доказывается SQL-тестом, а не только анализом.

`median` уже перехватывается `AdvancedAggregateTranslator.cs:160` по имени, затем `EmitMedian` (`:237`) требует `Dialect.QuantileAggregates` (`:239`); базовое значение — `null` (`SqlDialectBase.cs:183`), SQLite его не переопределяет, результат — исключение на `:240`. Эта семья требует отдельного решения и проверки compile-time capability.

### 2.3. Альтернативы

| Подход | Плюсы | Минусы / стоимость / риск |
|---|---|---|
| **Только `total`, существующий seam** | Два product-файла, нативная семантика, готовый provider guard | Четыре имени остаются в issue; низкая стоимость и риск |
| Все пять имён сейчас | Формально закрывает список #285 | Не доказан `SQLITE_ENABLE_PERCENTILE`; для `median` нужен dispatch fix. Риск повторения #278; отклонено |
| Эмуляция через другие агрегаты/SQL | Не зависит от percentile extension | Иная семантика empty/null/типов, больше SQL и поддержки; не минимально, отклонено |

**Выбор:** первый подход; оставшиеся функции не являются незавершённой частью этого DO.

## 6. Тестовая стратегия, варианты и приоритеты

### 6.1. Матрица вариантов

| Вариант | Закрытие |
|---|---|
| Value: integer/floating, положительные/отрицательные, дроби, повторы | SQLite SQL unit + live integration |
| Nullable value, mixed null/non-null, all-null | Live integration; null values игнорируются, all-null → `0.0` |
| Пустой исходный набор | Live integration: одна aggregate result value `0.0`, не `null` |
| Большие integer values | Live integration: floating result без integer-overflow поведения `sum` |
| Reference input, numeric/non-numeric text | SQL unit + SQLite integration: нативная SQLite coercion, не CLR conversion |
| `null`/`default` с явно заданным generic type | SQL unit; live null-case; compile-time return type — `double` |
| Column vs parameterized argument; alias | SQL unit: existing emission и parameterization; не inline CLR evaluation |
| Name dispatch: `total` против `sum`/прочих aggregate names | SQL unit: `total(x)` остаётся `total(x)`, не `sum(...)`; закрывает `NormSqlTranslator.cs:368,:448,:486` и `AdvancedAggregateTranslator.cs:29` |
| PostgreSQL, SQL Server, MySQL, MariaDB, ClickHouse | Пять SQL-generation guard tests, точное исключение R05 |
| InMemory | Core unit: то же `NotSupportedException` и сообщение R05; не исполнение facade как CLR-функции |
| Existing SQLite scalar/JSON aggregate functions | Regression unit suite; JSON1 aggregates не перерабатывать |
| Новые flags/cache modes | Их нет; guard — не добавлять mutable command flags и не менять планирование |

| Альтернативная SQLite build/runtime configuration | Deferred до отдельного runtime/capability запроса; не объявлять проверенной текущими тестами |
