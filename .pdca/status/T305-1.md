## 2. Минимальное решение и API
Суть: сначала проверить весь запрос и выбрать совместимый путь, затем исполнить ровно один раз. Ограничения: сохранить настройки, session/connection, ownership и явные значения. Оптимум: существующие команды/hooks плюс небольшие bulk-specific helpers, без strategy framework.
| Область | Решение |
|---|---|
| Mode | `BulkInsertMode { Auto, Native, Portable }`; options `Mode=Auto`; builder `Mode(BulkInsertMode)` |
| Destination | `string? SchemaName`, `DatabaseName`, `ServerName`; сохранить `TableName`/`TableSchema`; builder `Schema(string)`, `Database(string)`, `Server(string)`; прежние `Table(...)` неизменны |
| Temp | `BulkInsertTargetKind { Regular, LocalTemporary }`; options/builder `TargetKind`; default Regular; отображается на существующий temp mechanism |
| SQL Server | `SqlServerBulkInsertOptions` record, `bool? UseInternalTransaction`; nullable options-группа `SqlServer`; builder `SqlServer(SqlServerBulkInsertOptions)` |
| MySQL/MariaDB | Новых provider knobs нет; `AllowLoadLocalInfile` остаётся connection configuration |
| ClickHouse | `ClickHouseBulkInsertOptions` record: `int? MaxDegreeOfParallelism`, `bool? UseSession`; nullable группа `ClickHouse`; builder `ClickHouse(ClickHouseBulkInsertOptions)` |
| Session | null сохраняет configured session; true требует actual session id; false — явный sessionless non-temp запрос |
| Timeout | `TimeSpan? Timeout`, builder `Timeout(TimeSpan)`; удалить `TimeoutSeconds` и `Timeout(int)` без shims |
| Presence | Сохранить публичные типы/имена старых flags; внутренне передавать presence отдельно от bool, включая direct options initialization и explicit false |
| ClickHouse integration | ctors `(ClickHouseClient)`/`(ClickHouseDataSource)`; `UseClickHouse(ClickHouseClient)`/`UseClickHouse(ClickHouseDataSource)` |
Пустая typed-группа не создаёт запроса. Заданное поле чужой группы, включая false, отклоняется. На своём provider default-equivalent значение принимается по результату, не по наличию driver flag.
Extend-only: точечные исключения только timeout signatures и более строгая validation. Иных удалений/переименований/изменений формы существующих non-timeout членов нет.
| Альтернатива | Минусы | Решение |
|---|---|---|
| Все поля плоско | Неясный provider scope | Две typed-группы |
| Клон `BulkCopyType`, dictionary/raw flags | Ложная совместимость | Отклонить |
| `IBulkInsertStrategy` | Лишняя абстракция без consumer | Существующие hooks |
| Async producer queue | Backpressure/cancellation/ownership | Последовательный bounded chunk adapter |
| DDL-флаги | Новый scope и no-op риск | Не добавлять |
