## Goal

Honor a fluent `Where` declared on a `JoinInto` child source by composing it into the join's `ON` condition, and reject — loudly, before execution — every child-query shape that cannot be represented there. The silent drop in issue #309 must become impossible: either the predicate reaches the SQL/plan, or the call throws `NotSupportedException`.

### Acceptance criteria

| ID | Requirement | Positive case | Negative case |
|---|---|---|---|
| REQ-309-01 | Child `Where`, caller predicate and relationship keys all constrain matching children; repeated `Where` stays AND-composed | `9501 -> [9511,9512]`, `9502 -> [9521]`; child `9513` (`Tag = "skip"`) excluded | an excluded child must not materialize |
| REQ-309-02 | LEFT joins retain parents with no/all-filtered children; INNER joins exclude them | parent preserved with empty collection | child filtering must not become an outer `WHERE` that removes LEFT parents |
| REQ-309-03 | All five public overloads and M2M normalize exactly once | forwarding overloads produce one AND | no duplicated child predicate |
| REQ-309-04 | Unsupported child modifiers throw `NotSupportedException` at declaration, before preparation/execution | exception names the shape | never silent, never partially honored |

## Decision (contract the issue intends)

**Adopt: fold a supported child `Where` into `ON`; fail closed on every other child shape.**

Precedent: the single-query `LoadWith` path already reads `child.Condition` and folds it into the synthesized ON (`src/nextorm.core/Builders/EntityBuilderEagerLoading.cs:581-585`, `EagerLoadJoinIntoSpec` ctor `:1097`, AND at `:1117-1122`) and rejects every other child shape (`UnsupportedSingleQueryChildShapes`, `:574-579`). `JoinInto` has the fold missing and no shape guard — hence the silent drop.

Rejected alternatives: reject every child `Where` (rejects the issue's intended valid query, diverges from `LoadWith`); translate arbitrary child queries into derived joins (paging/ordering/grouping semantics + provider complexity, out of scope); keep the silent drop and document it (preserves the defect); fold into the outer `WHERE` (breaks LEFT-join parent preservation); cache-key-only change (a key cannot execute a missing predicate); reject only in Debug (Release stays silently wrong).
