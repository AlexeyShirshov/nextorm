# Введение

NextORM — библиотека высокого уровня для доступа к реляционным данным в .NET-приложениях. Она
использует специализированные библиотеки доступа к протоколам, например SqlClient для Microsoft SQL
Server и SQLite для SQLite, и помогает создать слой доступа к данным (DAL), не зависящий от
конкретной реляционной СУБД.

## Что делает NextORM

Библиотека выполняет две основные задачи:

- генерирует SQL-код;
- преобразует реляционные данные в типы .NET — классы, примитивные типы, массивы, списки и другие
  структуры.
