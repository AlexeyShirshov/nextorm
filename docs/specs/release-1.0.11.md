# План выпуска Nextorm 1.0.11

**Статус: подготовка, без публикации.** Ветка `1.0.11`, база `v1.0.10.2`, планируемый
стабильный тег `v1.0.11`.

- Скоуп: [майлстон 1.0.11](https://github.com/AlexeyShirshov/nextorm/milestone/24) —
  задачи #26, #34, #187, #404 (закрыты).
- Публичные заметки: [EN](../../CHANGELOG.md#1011) и [RU](../../CHANGELOG.ru.md#1011).
- Пакеты: `nextorm`, `nextorm.sqlite`, `nextorm.sqlserver`, `nextorm.postgres`, `nextorm.mysql`,
  `nextorm.mariadb`, `nextorm.clickhouse`, `nextorm.extensions`, `nextorm.entityframeworkcore`.
  Каждый пакет содержит ассеты `net10.0` и `net11.0`.

## Публикация владельцем

1. После успешной упаковки отправьте подготовленные изменения в ветку `1.0.11` и влейте её в
   `main` через PR.
2. На итоговом коммите `main` дождитесь успешных `build` и `aot`, включая оба гейта покрытия,
   и деплоя документации EN/RU.
3. Создайте и отправьте тег `v1.0.11` на проверенном коммите `main`. Тег запускает `publish`:
   CI упаковывает девять проектов с версией из тега и отправляет их на NuGet через OIDC.
4. Проверьте успешный `publish` и наличие версии `1.0.11` на nuget.org у всех девяти пакетов.
5. Опубликуйте стабильный GitHub Release для `v1.0.11`: используйте публичные заметки и
   ссылку на сравнение `v1.0.10.2...v1.0.11`. Закройте майлстон.
6. После публикации обновите `Version` в `Directory.Build.props`, `NextOrmVersion` в
   `examples/Directory.Packages.props` и проверьте примеры на опубликованных пакетах.
   До публикации эти значения остаются прежними.
