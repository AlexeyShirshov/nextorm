# Built-in function coverage: per-provider status

This document gives, for every supported provider, the status of the **built-in SQL functions** in
nextorm's query-building surface. It complements
[`sql-capabilities-gap-analysis.md`](sql-capabilities-gap-analysis.md) (which tracks query *constructs*)
and [`capability-matrix.md`](../comparison/capability-matrix.md) (which compares nextorm with EF Core and
linq2db): here the unit is the individual function.

## Scope and statuses

* **Supported providers:** SQLite, SQL Server, PostgreSQL, MySQL, MariaDB (`nextorm.mariadb`, built on
  MySQL) and ClickHouse. The in-memory provider renders no SQL and is excluded.
* **Canonical function list:** the documented built-in set of each vendor, grouped the way the vendor
  groups it (see [Sources](#sources)).
* **Implemented surface:** `SqlFunctions.Sql` (`CommonFunctions`), the per-provider surfaces
  `SqlFunctions.Postgres`/`SqlFunctions.SqlServer`/`SqlFunctions.MySql`/`SqlFunctions.Sqlite`/
  `SqlFunctions.ClickHouse`, and the built-in CLR-member translation (`StringFunctionTranslator`,
  `MathFunctionTranslator`, `DateTimeFunctionTranslator`, `ScalarFunctionTranslator`, the window and
  aggregate translators, `RegexSqlTranslator`, `StringFormatTranslator`).
* **Statuses:** every function is in exactly one of the four sections below.

| Status | Meaning |
|---|---|
| **Explicitly implemented** | rendered by a shipped `SqlFunctions.*` member (portable or provider-specific), or by a shipped provider dialect path that has no separate member |
| **Reachable via CLR translation** | no dedicated `SqlFunctions.*` member, but a built-in CLR-member translation emits the same vendor function (or the portable wrapper maps onto the vendor spelling); counted as covered |
| **Not implemented** | neither of the above emits it; a `[SqlFunction]` UDF or a raw SQL fragment can still reach it, but that escape hatch is deliberately **not** counted as coverage |
| **Out of scope** | deliberately not modelled — niche families (administration, metadata, permissions, encryption, spatial, network, external engines) |

The lists are a **vendor-catalogue inventory**, not a line-by-line verification against the code. Re-verify
against the vendor page before acting on any single entry.

## 2. Reachable via CLR translation

These have no dedicated `SqlFunctions.*` member, but a built-in translation emits the vendor function (or
a shipped portable member maps onto the vendor spelling), so they count as covered.

| Provider | CLR member / vendor function covered | Rendered as |
|---|---|---|
| **All providers** | `string.ToUpper`/`ToLower`/`Trim`/`TrimStart`/`TrimEnd`/`Substring`/`Length`/`Replace`/`Remove`/`Insert`/`IndexOf`/`LastIndexOf`/`PadLeft`/`PadRight`, `new string(char, n)`, `Split`/`Join`, `Contains`/`StartsWith`/`EndsWith`/`IsNullOrEmpty`, `+`/`string.Concat`, `??`, numeric casts | the provider's native string/coalesce/cast form |
| **All providers** | `Math.Abs`/`Ceiling`/`Floor`/`Round`/`Truncate`/`Sqrt`/`Pow`/`Exp`/`Log` (natural)/`Log10`/`Sin`/`Cos`/`Tan`/`Acos`/`Asin`/`Atan`/`Atan2`/`Sign`, `%` | the provider's math functions (`atn2` on SQL Server) |
| **All providers** | `DateTime.Now`/`UtcNow`/`Year`/`Month`/`Day`/`DayOfYear`/`Hour`/`Minute`/`Second`, `DateTime.AddDays`/`AddMonths`/… | the provider's date-part/date-add form |

| **SQL Server** | `LEN`/`LEFT`/`RIGHT`/`REPLICATE`/`REPLACE`/`SUBSTRING`/`CHARINDEX`/`LOWER`/`UPPER`/`TRIM`/`LTRIM`/`RTRIM`; `ABS`/`CEILING`/`FLOOR`/`ROUND`/`SQRT`/`POWER`/`EXP`/`LOG`/`LOG10`/`SIGN`/`SIN`/`COS`/`TAN`/`TRUNC` and `ACOS`/`ASIN`/`ATAN`/`ATAN2` | the T-SQL equivalents (`ATN2` for `Atan2`); `COT`/`DEGREES`/`RADIANS`/`PI` come from the portable surface |

| **MariaDB** | the MySQL mappings | same as MySQL, except `ANY_VALUE` (gated off, so it stays a gap — section 3) |
| **SQLite** | the portable set; `string`/`Math`/`DateTime`; `group_concat`; `iif`/`nullif`/`max`/`min`; `version`; date arithmetic and date parts | `string_agg`, conditional/`NULLIF`/`GREATEST`/`LEAST` forms, `sqlite_version()`, `strftime`/`date` respectively |

## 4. Out of scope

| Provider | Excluded families | Reachable through |
|---|---|---|
| **Cross-provider** | none | — |
| **PostgreSQL** | network (`host`, `masklen`, `broadcast`, `family`, `netmask`, `set_masklen`, `abbrev`, `inet_*`, `macaddr8_set7bit`); the range/multirange **function catalogue** (the portable `Range<T>` operator surface is tracked in the [capability matrix](../comparison/capability-matrix.md), not here); geometric; enum; `pg_*` metadata/permission helpers; XML (`xml*`, `xpath`, `xmltable`, …) | raw SQL or a `[SqlFunction]` wrapper |
| **SQL Server** | security/identity beyond the shipped `SUSER_NAME`/`ORIGINAL_LOGIN` (`SUSER_ID`/`SUSER_SID`/`SUSER_SNAME`/`SYSTEM_USER`, `HAS_PERMS_BY_NAME`, `IS_MEMBER`, …); metadata beyond the shipped A–D subset (`COLUMNPROPERTY`, `INDEXPROPERTY`, `sys.*`); system-statistical (`@@CPU_BUSY`, …); collation; rowset (`OPENROWSET`/`OPENQUERY`); cursor; AI (`AI_*`); vector (`VECTOR_*`); text/image (`TEXTPTR`/`TEXTVALID`); the `ENCRYPTBY*`/`DECRYPTBY*`/`SIGNBY*`/`VERIFYSIGNEDBY*`/`CERT*`/`KEY_*` family | raw SQL or a `[SqlFunction]` wrapper |
| **MySQL** | spatial (`ST_*`, `MBR*`, `Point`/`Polygon`/…, `ST_AsGeoJSON`). Full-text is only partially out of scope: it is covered through `contains`/`freetext` | raw SQL or a `[SqlFunction]` wrapper |
| **MariaDB** | geographic/spatial (same as MySQL) | raw SQL or a `[SqlFunction]` wrapper |
| **SQLite** | core scalars `changes`, `last_insert_rowid`, `likelihood`/`likely`, `load_extension`, `sqlite_compileoption_get`/`sqlite_compileoption_used`, `sqlite_offset`, `sqlite_source_id`, `total_changes`, `unistr`/`unistr_quote`, `zeroblob`, `json_error_position` | raw SQL or a `[SqlFunction]` wrapper |
| **ClickHouse** | external-engine table functions: `mysql`, `postgresql`, `sqlite`, `jdbc`, `odbc`, `mongodb`, `redis`, `hdfs`(`Cluster`), `s3Cluster`, `azureBlobStorage`(`Cluster`), `deltaLake`(`Cluster`), `iceberg`(`Cluster`), `hudi`(`Cluster`), `paimon`(`Cluster`), `bigquery`, `gcs`, `ytsaurus`, `arrowFlight`, `prometheusQuery`(`Range`), `input`, `view`, `format`, `null`, `executable`, `primes`, `merge`, `dictionary`, `eval`, `loop`, `fuzzJSON`, `fuzzQuery`, `timeSeries*` | raw SQL or a `[SqlFunction]` wrapper |
