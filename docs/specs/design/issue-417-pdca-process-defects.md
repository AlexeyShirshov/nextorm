# #417: дефекты процесса PDCA (N2)

## `issue417-check-workspace-root`
- Симптом: независимый CHECK целевого пакета не мог прочитать `.pdca/**` из изолированного ворктри; доступ отклонён политикой `external_directory`.
- Причина: рабочий каталог dispatch не совпадал с корнем, содержащим целевой пакет. Следствие: понадобилась повторная маршрутизация, новый продуктовый attempt не потребовался.
- Доказательства: `.pdca/issue-417/rv1/attempts/N2/report-0914ac044704e804836c6631f4a4607ddb074d996cc4cdcb1ee8653c2e7d85f9.md` §Lessons L03; `target-check-03/` и `target-successor/` в том же корне evidence.
- Предотвращение: запускать CHECK из корня назначенного evidence и переносить точную пару path/SHA, не расширяя разрешения.

## `issue417-monolithic-build-budget`
- Симптом: повторная монолитная сборка integration exit 124 при общем лимите 600 с.
- Причина: единое окно на последовательную сборку зависимостей и самой тестовой сборки. Следствие: live-проверка не стартовала, целевой C02 оставался непроверенным; это не провал продукта.
- Доказательства: `.pdca/issue-417/rv1/attempts/N2/N2-re-gather-01-integration-build.log`, `.pdca/issue-417/rv1/attempts/N2/target-check-03/integration-build-01.log`; в `target-successor/` 12 зависимостей и отдельная сборка exit 0 (205 с), первичный `receipt.json`.
- Предотвращение: собрать и закрепить выходы зависимостей на том же снимке, затем дать `--no-dependencies` отдельное ограниченное окно; сверить входы и DLL до live-прогона.
