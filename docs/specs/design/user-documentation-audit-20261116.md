# Documentation Audit: пользовательская документация nextorm (сводный отчёт первого прохода, 2026-11-16)

**Score:** не выставлена: постраничная десятистрочная диагностика и полная P11-верификация ещё не завершены.  
**Shippable:** no — подтверждены фактические ошибки о требуемом SDK, prerelease-статусе пакетов и `Count()` (D001, D008, D013).  
**Diagnostic:** десятистрочная диагностика корпуса не завершена, оценка корпуса и оценки отдельных страниц не выставляются.  
**Doc type / reader:** смешанный корпус README, руководств, how-to и справочников для пользователей библиотеки и разработчиков, которые настраивают, используют или вносят вклад в nextorm.  
**Language:** английский и русский; правила, помеченные `[EN]`, к русским страницам не применялись.  
**Local style guide:** репозиторные правила (в частности, суффикс `Async` только при наличии синхронной пары и CRLF); не выполнять массовое переименование заголовков, последовательно оформленных по принятому стилю проекта.  
**Blocking:** D001 — неверно указана версия SDK, необходимая контрибьюторам; D008 — семь README неверно утверждают, что для установки обязательно нужен prerelease; D013 — противоречивое утверждение о наличии entity terminal `Count()`.  

## Объём

Пользовательская документация на английском и русском языках: `docs/` и `docs/ru/` (без сгенерированных и внутренних материалов), корневые `README` и `CONTRIBUTING.md`, восемь README пакетов в `src/`, восемь README примеров и один `examples/VERIFICATION.md`. Материалы tools/Stryker и assets/promo просматривались попутно, но в пользовательский корпус этого аудита не входят.

## Метод, охват и ограничения

Выполнен комплексный первичный статический аудит пользовательского корпуса и чтение прозы; потоки чтения и их происхождение зафиксированы в [reading-coverage.md](user-documentation-audit-20261116-evidence/reading-coverage.md). Подтверждённые замечания и отсеянные ложные срабатывания отражены в [triage-decisions.md](user-documentation-audit-20261116-evidence/triage-decisions.md), подтверждённые оборванные фрагменты — в [confirmed-prose-corruption.json](user-documentation-audit-20261116-evidence/confirmed-prose-corruption.json), а результаты целевой проверки символов Roslyn — в [api-verification.md](user-documentation-audit-20261116-evidence/api-verification.md). Инвентарь охватывает 209 файлов и 66 836 строк: 190 документов EN/RU, два корневых документа, восемь README пакетов, восемь README примеров и один `VERIFICATION.md`. Сводка и компактный manifest ровно на 209 записей сохранены как [summary.json](user-documentation-audit-20261116-evidence/summary.json) и [manifest.compact.json](user-documentation-audit-20261116-evidence/manifest.compact.json). Все 209 SHA-256 из manifest независимо совпали с текущими файлами; изменений источников — 0. Некоторые потоки сохранили только контрольную точку или номер последней прочитанной строки, а инструментальный вывод усекал отдельные чрезмерно длинные строки. Поэтому это не завершённая постраничная десятистрочная диагностика и не сертификация всех API/примеров. Целевая проверка Roslyn завершена для указанных quickstart/DI/provider signatures, vector basic types и отдельных агрегатных API; полная API/P11-проверка остаётся незавершённой. Копии evidence-файлов сохранены в каталоге отчёта; для текстовых файлов нормализованы только окончания строк. Результаты ниже — конкретные замечания и кандидаты на правку, а не утверждение, что весь корпус или каждая страница непригодны.

Сборка, тесты, примеры и DocFX не запускались. Полная проверка развернутого сайта не проводилась; выполнены только перечисленные ниже read-only spot checks. Roslyn подтвердил перечисленные сигнатуры quickstart/DI/provider overloads и базовые типы vector guide, но не все API и runtime behavior. `VectorSearch` method/provider validation, CSV, AOT и широкие runtime guarantees остаются непроверенными; D006 — только кандидат, семантика не проверена и ошибка выполнения не установлена.

- [LINQ Phase 0 plan](https://alexeyshirshov.github.io/nextorm/superpowers/plans/2026-10-04-linq-phase-0-plan.html) — HTTP 200, ожидаемый заголовок.

Конфигурация DocFX включает 27 Markdown-файлов `docs/superpowers/`; из них фактическое попадание на сайт подтверждено для двух перечисленных в evidence страниц. Статус остальных 25 страниц этой проверкой не устанавливался.
