## Explicit non-applicable row

`collection-element` placement is **not applicable**, not a silent skip: JSON arrays are
provider-native whole-column values (rank-one `T[]`); there is no per-element object-construction
lowering path, and an array whose element type is a construction type is rejected by the existing
array-element classification (`JsonShapePlan.Classify` for the element type) rather than flattened.
