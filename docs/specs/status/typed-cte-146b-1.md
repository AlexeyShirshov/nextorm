# #146-B — recursive typed CTE (cycle 1)
Milestone: 1.0.9-rc1 (issue #146). One group, current worktree/branch `1.0.9-b`. Baseline slice A = `a2f2295`.

## Goal
Recursive typed CTEs: anchor defines shape, callback builds the step once via an owned self-reference, result reused via `From`.

## Acceptance criteria
AC1 exactly two overloads `AsRecursiveCte(name, step)` and `AsRecursiveCte(name, step, int maxRecursion)` -> `Cte<TResult>`; `From(CteReference<TResult>) -> EntityBuilder<TResult>`; no nullable/default maxRecursion.
AC2 callback called exactly once at construction; anchor+step joined by automatic `UNION ALL`; null callback/null result -> `InvalidOperationException` before DB.
AC3 self-ref takes anchor shape; scalar/anonymous/DTO/entity/join projections preserve member/slot->column; mismatch in count/order/identity/declared CLR/bound provider type/nullability -> `InvalidOperationException` before DB, no unwrap/widen, diagnostic names CTE+branch+position.
AC4 self-ref only with matching owner token across nested query expressions; foreign/unbound ref, captured-ref-outside-step, anchor self-access -> `InvalidOperationException` before DB; name equality is not owner equality.
AC5 `CteMerge`/`CteHoister` keep deps/order/single definition; only the matching self-edge of the recursive definition in its step is exempt from cycle detection; ordinary/mutual cycles still rejected.
AC6 PostgreSQL/SQLite/SQL Server/MySQL8/MariaDB use existing recursive SQL; typed recursion on ClickHouse -> `NotSupportedException` before DB; ordinary typed CTE on ClickHouse still works.
AC7 `maxRecursion` keeps existing semantics (SQL Server hint + `OPTION(...)` fold); omission adds no hint; other providers keep existing ignored-hint behavior; no new global default/emulation.
AC8 CTE reused by multiple consumers; no shared `QueryCommand` mutation, no sticky cache flags; owner/shape validation not bypassed by cache.
AC9 real DBs confirm bounded recursion/materialization/empty anchor/`UNION ALL` duplicates; SQL Server limit/default/unlimited; skipped != pass.
AC10 Debug+Release 0/0; coverage line>=85 branch>=75; EN+RU docs+register+mutation+perf closed.
