## 4.4 Как воспроизвести расчёт

```bash
python3 - <<'PY'
import sqlite3, json, collections
c = sqlite3.connect("file:/home/alex/.local/share/opencode/opencode.db?mode=ro", uri=True)
per = collections.Counter()
for sid, data in c.execute("SELECT session_id, data FROM message"):
    d = json.loads(data)
    if d.get("role") == "assistant" and (d.get("cost") or 0):
        per[f"{d.get('providerID')}/{d.get('modelID')}"] += d["cost"]
print({k: round(v, 4) for k, v in per.items()})          # весь аккаунт по моделям
PY
```

Разбивка по рукам/слоям/целям — тем же запросом с join на `session.directory`/`session.title`
(каталог clean-room ворктри / `eval-wt/<arm>-judge|port` / заголовок `eval-lN/<arm>`).
