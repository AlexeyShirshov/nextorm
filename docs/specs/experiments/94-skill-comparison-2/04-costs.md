# 04 — Деньги и время (прогон №2)

Данные — из локальной БД сессий `~/.local/share/opencode/opencode.db` (поле `cost` в сообщениях
ассистента, USD по каждой модели отдельно; родитель + подагенты) и из логов harness (wall-clock).
Артефакты — `exp94/logs/`, `exp94/report/summary.tsv`, `exp94/eval/out/*.jsonl`.

## 4.1 Прогоны рук

Среда всех рук — `deepseek/deepseek-flash`. В прогоне №2 у a3 — **25 подагентов**, у a2 — 2, у a1 —
0; поэтому «родительская» строка `summary.tsv` сильно занижает цену a3.

| рука | rc | wall (акт.) | стоимость (родитель + подагенты) | файлов | своих тестов |
|---|---|---|---|---|---|
| a1 (bare) | 0 | 20.9 мин | **$0.2147** (1 сессия) | 37 | 3 |
| a2 (skill) | 0 | 41.9 мин | **$0.3683** (3 сессии: 0.2683 + 2 пода) | 43 | 8 |
| a3 (PDCA) | 0 | 78.6 мин | **$0.7617** (26 сессий: 0.0955 + 25 подов) | 37 | 8 |
| **итого руки** | | | **$1.3447** | | |

- `summary.tsv` показывает **только родительскую сессию**: у a3 это $0.0955 против реальных
  $0.7617 (25 подагентов), у a2 — $0.2683 против $0.3683.
- PDCA дороже bare в **~3.5×** и длиннее в **~3.8×**; `implementing-todo-features` — в **~1.7×**
  дороже bare при наилучшем результате среди рук.
- **Wall-clock a3** в `logs/a3.log` — `38223` с: ночью хост уходил в сон, и один разрыв между
  событиями составил 557.9 мин (00:05→09:23). Активное время (сумма пауз < 5 мин) ≈ **4716 с**
  (78.6 мин) — именно оно в таблице; это значение внесено в `report/summary.tsv`.

## 4.2 Стоимость оценки (single-DS арбитр)

Судит **один агент** `deepseek/deepseek-flash` на цель (L2 + L3); субагентов нет.

| цель | L2 судья | L3 аудит | итого оценка |
|---|---|---|---|
| a1 | $0.0403 | $0.0355 | **$0.0758** |
| a2 | $0.0657 | $0.0520 | **$0.1177** |
| a3 | $0.0369 | $0.0584 | **$0.0953** |
| upstream | $0.0205 | $0.0485 | **$0.0690** |
| **итого** | $0.1634 | $0.1944 | **$0.3578** |

Для сравнения: прогон №1 (two-tier, brains на `gpt-6-sol`) стоил **$1.5976** на 4 цели; Opus —
$9.6701. То есть single-DS оценка **в ~4.5× дешевле** two-tier и **в ~27×** дешевле Opus. Это
плата за слепоту: single-DS видит код руки (см. `06-caveats.md`).

## 4.3 Общий итог

| статья | $ |
|---|---|
| прогоны рук (a1+a2+a3, родитель + подагенты) | 1.3447 |
| оценка single-DS (L2+L3, 4 цели) | 0.3578 |
| **итого прогон №2** | **≈ $1.70** |

Экономика: самая дешёвая рука — bare ($0.21), но она лишь на 5 баллов ниже лучшей (a2, 80 против
75) при вдвое меньшей цене; PDCA — самая дорогая ($0.76) и последняя по рубрике. Оценка при этом
дешевле самих прогонов — в отличие от прогона №1, где Opus-судейство было дороже всех рук вместе.

## 4.4 Как воспроизвести расчёт

```bash
# стоимость рук с подагентами (родитель + дети):
python3 /home/alex/sources/nextorm-experiments/exp94/dbmetrics.py

# стоимость судейства (стенограммы агентов):
python3 - <<'PY'
import json, glob
tot = 0.0
for p in glob.glob("/home/alex/sources/nextorm-experiments/exp94/eval/out/*.l[23].jsonl"):
    for line in open(p, encoding="utf-8", errors="replace"):
        try: o = json.loads(line)
        except Exception: continue
        st=[o]
        while st:
            d=st.pop()
            if isinstance(d, dict):
                for k,v in d.items():
                    if k=="cost" and isinstance(v,(int,float)): tot+=float(v)
                    st.append(v)
            elif isinstance(d, list): st.extend(d)
print(round(tot,4))
PY
```
