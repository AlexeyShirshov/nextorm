# W-2 verification — two paged navigations sharing one ORDER BY (T211 r1 n2/3)

- Anchor: `src/nextorm.core/Builders/EntityBuilder.cs:1639-1658` (`AppendEmbeddedChildOrdering`),
  consumed at `:1509`.
- Question: with two paged navigations each yielding **more than one** row per parent, does a later
  navigation's own order get lost or contaminated by the concatenated single `ORDER BY`?

## Verdict: no violation on the reachable shape; evidence retained.

Probes (both green, `Feature=D211`):

- `tests/nextorm.sqlite.tests.EagerLoadPerParentPagingEdgeTests.SingleQuery_TwoPagedNavigations_WithMultipleRows_ArePagedIndependently`
  — children `Limit(2)` by SortKey and notes `Limit(2)` by Rank; asserts each collection's page
  membership is decided inside its own partition.
- `tests/nextorm.sqlite.tests.EagerLoadPerParentPagingEdgeTests.SingleQuery_TwoPagedNavigations_KeepEachNavigationsOwnOrder`
  — children `Limit(3)`, notes `Limit(3)`; asserts `Children.SortKey == [10,20,30]` and
  `Notes.Rank == [1,2,3]`, i.e. **both** navigations keep their own order.

Observed pair statement (`check/W-2-two-nav-sql.txt`):

```
... order by t1.id, t3.SortKey, t5.rank
```

Each navigation is an independent ranked derived source (`row_number() over (partition by parent_id
order by sort_key|rank)`), so the page membership is per-partition. The outer denormalized order is
`parent, child1-key, child2-key`: the first child's block enumerates **every** row of the second
navigation in that navigation's own order, so the stitcher's first-occurrence assignment yields the
second collection in its own order as well; the first collection's own keys lead, so it is ordered too.
The reachable layout (sibling one-to-many collections joined from the parent) therefore cannot
contaminate either order. A later navigation's order would only be at risk if its rows did not appear
inside the first child's block, which cannot happen for a parent-keyed sibling collection.

No production change made (recording the reachability argument, not speculatively fixing).
