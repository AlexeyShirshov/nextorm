# V9 applicability — derived / `As` / value-projection child source

- variant: V9 (unsupported child shape: derived source)
- observed predicate: a `LoadWith` child whose primary source is a derived subquery, i.e.
  `_query is not null || _from?.SubQuery is not null` on the resolved child builder.
- verdict: **applicable** (the shape is reachable through the public child factory), and **fail-closed in both eager modes**.

## Reachability

The public `LoadWith<TChild,TKey>` child factory is `Func<IDataContext, EntityBuilder<TChild>>`
(`EntityBuilder.cs:631-637`). A caller can return a derived builder via
`c => c.From(c.From<Child>().Where(...).Select(...))`, because `From<TResult>(this IDataContext, QueryCommand<TResult>)`
(`DataContextExtensions.cs:1255-1257`) and `From<TResult>(this IDataContext, EntityBuilder<TResult>)`
(`DataContextExtensions.cs:1374-1376`) construct `new EntityBuilder(dataProvider, query)`, which sets `_query`
(`EntityBuilder.cs:71-76`).

## Guard chain (both modes)

- Shape predicate: `EntityBuilder.UnsupportedChildShapes` reports `"derived (As) source"` at
  `src/nextorm.core/Builders/EntityBuilder.cs:1278` (`_query is not null || _from?.SubQuery is not null`).
- Split mode: `BuildChildCommand` calls the shared guard when the child pages per parent —
  `EntityBuilderEagerLoading.cs:358-369`; preparation seam `MarkPerParentTopN` also calls
  `IEagerLoadSpec.ValidatePerParentPaging` at `EntityBuilderExtensions.cs:505-521`.
- Single-query mode: `IEagerLoadSpec.ToJoinIntoSpec` rejects via `UnsupportedSingleQueryChildShapes`
  (`EntityBuilderEagerLoading.cs:270-275`); the paged child instead routes through
  `ToPerParentPagingJoinIntoSpec`, which calls the same shared `ValidatePerParentPagingChild`
  (`EntityBuilderEagerLoading.cs:301-303`).
- Shared guard: `ValidatePerParentPagingChild` at `EntityBuilderEagerLoading.cs:575-592` throws before any SQL.
