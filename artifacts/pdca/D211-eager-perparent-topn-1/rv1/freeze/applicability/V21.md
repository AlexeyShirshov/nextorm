# V21 applicability — public window version-negotiation flag / unsupported derived-source-form rejection

- variant: V21 (unsupported window/version flag; unsupported derived-source form)
- observed predicate, part A (version flag): a **public** window version-negotiation flag, method or option
  that a caller could set to request/reject a window form.
- observed predicate, part B (derived-source form): an unsupported derived-source form that must be rejected.
- verdict: **A = N/A** (no such public surface exists); **B = applicable and already rejected** (see V9/V11).

## Proof — no public window version negotiation

- `ISqlDialect` window capabilities are read-only boolean constants (no setter, no version input):
  `src/nextorm.core/DataContext/Dialect/SqlDialectBase.cs:110-122` (`SupportsNamedWindows`,
  `SupportsWindowFrameGroups`, `SupportsWindowFrameExclusion`, `SupportsInFrameWindowFunctions`, all
  `public virtual bool ... => false;`), declared on the interface at
  `src/nextorm.core/DataContext/Dialect/ISqlDialect.cs:359-381`.
- There is no `WindowVersion`/`MinVersion`/window-version flag anywhere in `src/nextorm.core` (grep for
  `WindowVersion`, `VersionFlag`, `SupportsWindow` finds only the constant capability properties above).
- `DataContext.ServerVersion` is `protected` and unrelated to window negotiation:
  `src/nextorm.core/DataContext/DataContext.cs:160` (`protected Version? ServerVersion => _serverVersion;`).

## Proof — unsupported derived-source form

The unsupported derived-source rejection is the same shape predicate as V9/V11
(`EntityBuilder.cs:1278`) and is closed by the V9/V11 fail-closed tests. No separate V21 test is needed.

## Consequence

No new `ISqlDialect` member and no public option is added. The task constraint "no new `ISqlDialect` member"
is compatible with the observed surface.
